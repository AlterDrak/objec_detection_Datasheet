Akses Kamera Terhambat (Browser Security)

Sistem mendeteksi bahwa browser Anda memblokir akses kamera pada halaman ini. Hal ini terjadi karena aturan keamanan browser terkait Secure Context (Protokol Aman).

Penyebab Utama:

Browser mewajibkan koneksi aman (HTTPS) atau 'localhost' agar fitur kamera (getUserMedia) dapat diaktifkan.

Cara Mengatasi (Pilih Salah Satu):

  1. Gunakan HTTPS (Direkomendasikan):

    Akses kembali website ini dengan protokol HTTPS aman:
    Beralih ke HTTPS

  2. Konfigurasi Chrome Flags (Khusus HP Android/Chrome):

    Jika ingin tetap menggunakan HTTP biasa tanpa SSL, Anda bisa melakukan bypass dengan langkah berikut:

    • Buka tab baru di Chrome HP Anda dan ketik: chrome://flags/#unsafely-treat-insecure-origin-as-secure
    • Ubah status menjadi Enabled.
    • Masukkan alamat website ini pada kolom teks:
    • Klik tombol Relaunch di pojok kanan bawah Chrome untuk memuat ulang browser.
  3. Gunakan Localhost:

    Jika Anda mengakses dari komputer server sendiri, pastikan alamat di URL browser menggunakan http://localhost:5000 atau http://127.0.0.1:5000.
